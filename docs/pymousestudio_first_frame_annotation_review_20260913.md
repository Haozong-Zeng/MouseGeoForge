## 应先处理的问题

### 1. 区分真实尾尖与画面/遮挡截断点

camA 的14号为(4.375,793.75)，距左边界4.375像素；camD为(329.375,1196.25)，距最后一行2.75像素。结合原图，尾巴在这两个视图被画布截断，而非看到真正的解剖末端。

不能将裁切处当 `tail_tip=visible`。应让标注员确认真正尾尖是否在画外；若确定则记 `out_of_frame`、坐标null；若被遮挡且无法定位则 `unlabelable`。可把现有坐标另存为可见尾段端点，不能继续占用真尾尖槽位。本次没有代改原坐标。

### 2. 继承的合成语义歧义，不应全部归咎标注员

除E外，6号 spine_center 与23号 abdomen_center 的距离分别仅 A2.50、B1.25、C2.80、D1.77、F3.75、G7.60像素；多张侧视二者都在背部。

这与旧 Cylinder 导出器中两点共用骨骼起点的问题一致。如果要沿用旧内部骨骼点，应明确为不可直接观察的代理且不作为独立腹部标志；如果要真实腹部表面中心，需要新定义与新映射，不能只让标注员挪点后仍声称与旧合成GT等价。

camA的21/22号位置靠足部近端；19/20的肘/腕定义同样尚未冻结。图像不足以确认真实内部膝肘中心，不能将这些落点直接当精准关节GT。耳、head_center、躯干点也应按此前 `deferred_definition` 规则审核。camE的2号位于头部装置区域，尤其不能自动视作皮肤可见点。

### 3. 缺失与可见性必须补录

现在无法区分“看得见”“根据其他视角推测”“遮挡无法定位”“画外”“定义待定”“漏标”。例如camF可看见耳廓，但没标耳点，可能是主动遵守定义暂缓，不能擅自推断为不可见。

建议至少为鼻、四爪、尾根/尾尖补录上述状态；对保留的其余点标注定义待定或推测状态。保持动物解剖左右，不按屏幕左右；本次未发现足以证明全局左右反标的证据，但也没有完成3D同名点一致性验证。

### 4. mask可以保留，但不是无需复核的最终版本

7图主体轮廓总体贴合真实鼠，没有把大块背景或玻璃倒影单独标为另一只鼠。各图包含尾巴，故是**含尾可见动物mask**，不能把它派生的框称为body-only框。

camA对后足细指描绘较多；侧视脚趾与毛边普遍较粗，camF尾部折返区域应局部复核。分割应保留真实遮挡/空隙，不能为了一个连通域画桥。本轮只检查这一时刻，不能推断全包mask质量。

### 5. 尾部中间点不能直接用于多视角3D

09–13目前是手工离散点，JSON没有弧长、骨段或同一实体点的定义。不同视图的透视缩短、尾巴出画与自遮挡，会导致“按每图可见长度分段”的点不对应同一物理位置。

建议优先标可见尾巴中线折线，遮挡处分段；尾根和真实尾尖单独带状态。后续派生采样需 `derived` 标记，不把各视图2D等弧长采样直接当同一3D点。本轮未强制连接这些点生成骨架，也没有三角化或重投影精度结论。
