# 尾部点监督 vs 曲线监督（2026-09-10）

用户授权推进下一步。本轮为新的一次有界实验，不重启已暂停的旧自动阶段链。
源误差审计：`tools/diagnose_tail_errors.py`，输出
`output/tail_supervision_v1/tail_diagnostic.json`，按原固定对的相机、标注可见性、
尾部通道、帧及投影弯曲度分解。弯曲度是二维弧长/端点弦长，不是三维曲率。

## 锁定对照

两个条件：额外尾部点监督、额外尾部曲线监督；原先的全部监督均保留，
额外权重均为1。原V4 seed29无额外监督作为冻结外部基线。
精确复用该失败种子的800步日程、初始化、相机顺序、源数据与lr3e-6；
768长边、每组1800图像/2633184 patch tokens，冻结encoder，保留生产模型。

曲线沿 Core23 的 tail_base/q1…q5/tail_tip 顺序做 Catmull–Rom 插值，
每段5采样点，端点保留；点与曲线两组均使用按GT框像素对角线归一化的
Smooth-L1位置误差。同一顺序参数对应，不使用无序Chamfer，避免首尾交换。
无强制拉直、无最小长度、无额外平滑项；缺失标签的段不跨越插值。
有坐标的遮挡点照常监督；未标注坐标不参与。NaN在插值前清理并屏蔽梯度。

这只是**曲线监督开/关的先导实验**，不改变关键点头为曲线控制点头，
也不是完整2×2×2消融。GT曲线是稀疏标记插值，不是实际尾部轮廓；
可能在急弯处过冲，不能把拟合曲线当真实几何。

判定：原13项保留/改善门槛不变；额外要求固定对尾部NME比原seed29至少改善5%，
各组非尾部NME不劣化超过5%。同时比较点辅助与曲线辅助；仅曲线胜过无辅助
不能证明曲线优于简单重加权。只评固定最终步，不挑中间checkpoint。
最多两组×800步、2小时、32GiB RAM LRU，无新磁盘特征缓存；不自动扩大预算。

## 关键诊断修正：不能把大误差仅解释为尾部几何

frame296、相机0中，被框匹配给实例1的高置信度预测：

| 模型 | objectness | 对该GT框IoU | 身体对本鼠/另一鼠NME | 尾部对本鼠/另一鼠NME |
| --- | ---: | ---: | --- | --- |
| 原模型 | 0.99999 | 0.0757 | 0.514 / 0.198 | 0.662 / 0.840 |
| V4 seed29 | 0.99999 | 0.0671 | 0.489 / 0.277 | 1.329 / 0.284 |
| V4 seed43 | 0.99999 | 0.0704 | 0.485 / 0.271 | 1.297 / 0.302 |

它按现有IoU0.5定义并未正确检测到该实例，而且身体也更接近另一只鼠。
这支持“漏检/重复实例预测或实例归属混淆”的诊断，不只是尾部弯曲回归错误。
框匹配NME给所有GT分配query，即使该query定位失败，故尾部均值会被这种案例放大；
检测感知PCK已把失败算进去，不应为指标好看而删除困难帧或临时改匹配规则。
此处的跨实例距离是诊断证据，不是对内部机制的因果证明。

下一步优先审计双鼠query分离、训练与评估匹配差异、mask/box定位一致性和
objectness与定位质量的脱节。对检测成功的实例另报条件尾部NME，同时保留
全部GT的检测感知指标；再考虑局部实例特征约束/质量评分的单因素实验。
曲线监督实现保留为未来尾部消融开关，不在此继续加量或升为生产默认。
