# 局部采样网格梯度审计 V1

2026-09-10，自动循环阶段4。结果：**当前证据不支持优先启动 detach-only 训练**。
未更新权重、未修改默认头、未启动新的800步实验；不能将此结论扩大为“detach一定无用”。

## 固定协议

从 V2 新采样协议的训练池按场景排序等间隔选4个 Cylinder 姿态和4个双鼠姿态，
不按开发指标挑选。Cylinder 源帧1/30/62/91，各取实际训练日程中底视单视、顶视
单视，以及首次出现的V2/V3/V4组合；双鼠使用原始双视图，总计24条输入。
比较原始checkpoint及已完成V2适应checkpoint，不使用失败的粗辅助checkpoint。

同一输入只编码一次，完整路径与detach路径共享冻结 RGB 特征。只改变
`detach_local_sampling_grid`，比较全部前向输出及损失，原Hungarian匹配相同。
设置与当前pilot一致：热图显式loss=0、粗辅助=0、最终坐标smooth-L1权重5，
深度及其余pose损失不变。切断的是采样位置对coarse的间接梯度，不切断
`refined=coarse+delta` 的显式梯度，不切断局部token/pixel特征路径。

分别对坐标loss和完整depth+pose loss求梯度，检查内部coarse tensor、粗坐标MLP、
shared adapter。这里都是裁剪前梯度、normalized UV空间，不是AdamW更新后的实际
像素移动；不能将参数梯度余弦直接等同于下一个训练步的精度变化。

定义：`g_indirect = g_full - g_detach`。把coarse到GT的向量作为参考；若
`-g_full` 背离GT但 `-g_detach` 朝向GT，记为“有害方向逆转”。仅身体16点汇总，
训练loss仍保留原有23点语义；零范数向量的余弦记为未知，而不是0。

预先写入协议的继续训练条件：两个checkpoint都至少在4个Cylinder源姿态中的
3个上，有≥10%的身体点发生这种逆转。这是有限规模实验的实用筛选条件，
不是显著性检验；不因事后某个梯度数值看起来不利而改变它。

## 结果

| checkpoint / 视角 | 有效身体点 | 间接梯度下降方向背离GT | 有害方向逆转 | 完整/直接梯度平均余弦 |
|---|---:|---:|---:|---:|
| 原始 / Cylinder底 | 176 | 54.0% | 0% | .9807 |
| V2 / Cylinder底 | 176 | 76.1% | 0% | .9721 |
| V2 / Cylinder侧 | 352 | 67.9% | 0.57% | .9686 |
| V2 / Cylinder顶 | 176 | 82.4% | 1.14% | .9383 |
| V2 / 双鼠侧 | 128 | 74.2% | 2.34% | .9798 |
| V2 / 双鼠顶 | 128 | 82.0% | 0.78% | .9706 |

两个checkpoint均不满足预先条件。四个Cylinder源姿态在原始checkpoint的逆转率
都是0，V2分别约0.57%、0.57%、0%、1.14%。因此不能只引用“76%间接梯度背离”
就宣称整体更新方向错误。

参数级（24条输入的算术均值）：

| V2参数 / loss | 完整/直接梯度余弦 | 间接/直接梯度余弦 | 间接范数/直接范数 |
|---|---:|---:|---:|
| coarse MLP / 坐标或总loss | .9648 | -.6727 | .2686 |
| shared adapter / 坐标loss | .9876 | -.5527 | .1922 |
| shared adapter / 总loss | .9994 | -.2661 | .0341 |

存在负相关间接梯度，但其大小不足以普遍逆转方向。在shared adapter的完整
训练目标中，这项差异更小。负相关不代表必然有害，局部采样对特征选择的
反向作用也可能是优化的一部分。该审计并未排除梯度尺度、曲率、训练中不同
checkpoint或样本造成的长期影响，只表明“它主要把粗点推反了”的简单解释缺乏支持。

## 验证与视觉检查

- 24次encoder、96次head前向及分项梯度，耗时52.3秒，无optimizer步骤。
- 两模式全部前向输出最大差异0，loss相同；coarse tensor上坐标分项与总loss
  梯度最大差异0，符合当前热图/粗辅助均为0的依赖关系。
- 每次诊断后检查非encoder模型state逐值哈希，源文件/代码/checkpoint校验通过。
- 134项unittest通过。历史实验运行状态为completed，GPU无其他计算任务后才开始。
- 实际查看 `gradient_routes.png`：右图间接不利方向占比较高，而左图真正逆转
  几乎为零，支持把这两种现象分开报告。

产物：`output/cylinder_grid_gradient_audit_v1/` 内有 protocol、report、逐点梯度
统计、参数梯度统计及图；不保存大体积中间特征或修改生产checkpoint。
代码：`mousegeoforge/grid_gradient_audit.py`、`tools/audit_cylinder_grid_gradients.py`。

## 下一步

不执行机械排队的detach训练，也不把这项只读审计计为新的失败训练方法。
下一项先量化**相同相机组合下训练姿态和开发姿态的泛化差距**：固定V2全部16个
Cylinder训练姿态，比较底/侧底/两侧底/四视图和旧侧视对，并检查双鼠回放训练池。
使用原始、V2以及已失败粗辅助的保存权重，比较粗/最终身体误差与窗口覆盖；
不得把不同相机组合造成的差异归为动作泛化，也不能把训练拟合当独立验证。
根据训练是否已拟合、额外粗监督是否只改善训练，再判断下一项应是增加源姿态
多样性、保留约束，还是局部头设计，而非再次盲目加loss或步数。
