**不实例化KeypointHead，无关键点预测损失，无关键点梯度进入encoder。** 解冻发布camera/depth head及encoder最后两个frame/inter-frame block，冻结confidence投影和camera/register输入token。

| 数据/约束 | 本轮用途 |

| 新随机rig、既有合成底视 | 相机测地线旋转、平移方向/基线、FoV；camera-Z、中心化身体形状、预测相机＋深度联合转移 |

| DANNCE1 | 相机监督；伪深度不参与测量GT监督 |

## 优化与梯度证据

- head峰值LR `1e-5`，encoder峰值 `1e-6`，前500次**优化器更新**warmup，随后余弦下降到峰值的10%。这里没有随机初始化的新head。
- 前16个预登记微批测量各几何任务对全部共享可训练encoder参数的梯度范数；用其中位数倒数定权重，限制 `[0.01,100]`，之后固定。不用验证分数调系数。
- 梯度累积后再裁剪，阈值10；记录裁剪前范数和被裁剪比例。每100更新记录各项原始/加权梯度范数及夹角，检验任务冲突。裁剪不等于AdamW每步更新相等，旧depth改善的归因仍未得到证明。
- 相对旋转使用 `atan2(sinθ,cosθ)` 测地线项；仅保留0.05弦距离稳定项。CPU夹具检查0/90/179/179.9/180度，接近180度梯度有限且非零；不声称SO(3)在精确反向点存在全局唯一导数。
- EMA为主验证权重，最高decay0.999并采用启动期衰减；发布权重step0固定参照，最终同时保留raw与EMA结果，不挑有利中间checkpoint。

首轮seed17，**4,000次更新＝32,000微批，最多8小时**；每250更新保存模型/EMA/优化器/RNG，每500更新EMA验证。新目录独立STOP和共享GPU锁；旧STOP继续保留，旧自动化不启用。

这是训练配方整体重启，不是单因素消融；即使v2恢复几何，也不能单独归因为移除关键点损失。真实标注跨视角对应的536个训练相机包已全部检查，均有共享已知点，最少2个有向点对，不按模型质量过滤。新渲染几何使用像素数组坐标，resize的K包含像素中心仿射；人工标签沿用有效版本的既有坐标约定。

## 验证与晋升

1. **未见rig主门槛**：全部新留出rig/动作；rotation中位数/P95降低≥30%，绝对P95 rotation≤10°、平移方向≤15°；预测相机＋深度转移coverage32至少+5pp；不可逐帧用GT拟合尺度。
2. **已知rig几何诊断**：71个留出标注组使用完整提供K/E，报告标注射线重投影及几何保留；预测相机分数不作晋升门槛。这个诊断使用人工源点，不等于部署自动关键点精度或实测毫米3D精度。
3. **其他视角保留**：固定支持下转移、中心化形状和逐来源误差不能出现旧实验的崩塌；旧合成动作留出若共享训练rig，必须明确标为动作留出而非rig泛化。
4. **关键点阶段后移**：几何达标后先冻结encoder，以`1e-4～3e-4`训练独立2D head至收敛，作为冻结基线；随后适配比较从同一收敛head起步。任何诊断probe都detach特征、独立优化和裁剪。三维关键点继续等待几何与定位验收。

未知真实稠密depth/可见性/3D保持未知；GR2/UR2/UR3、DANNCE2及原合成TEST动作不进入训练或方法选择。
