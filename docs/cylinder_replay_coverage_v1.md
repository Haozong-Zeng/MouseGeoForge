# 双鼠回放覆盖审计（2026-09-11）

## 结论

**暂不启动增加回放姿态数量的训练。** 混合模型在同源、未用于最近800步回放的
16个姿态上，Core23 NME只比8个已回放姿态高 **1.29%**；两组检测召回均为100%。
没有达到预先锁定的“未回放误差至少高15%”机制门槛，因此不能把退化简单归为
记住8个姿态、其他姿态无法识别，也不能据此直接增加训练量。

但确有较广泛的身体定位退化：已回放/未回放身体NME分别比原始模型高约
**10.1%/10.5%**。未回放16个姿态中只有1个身体NME改善。下一步优先检查
Cylinder训练目标与双鼠身体定位在共享参数上的梯度冲突，而不是立即开新loss。
当前这只是候选解释，尚未验证冲突，更不代表已确定根因。

本轮无optimizer更新，无新数据或生产修改；连续无实质改善训练方法计数仍为1。

## 数据与协议

- 8个原双鼠回放姿态，另从原manifest明确train、同source_group且排除这8个的
  候选中，按 `source_frame` 排序等距选16个。清单在预测前锁定，没有按误差挑样本。
- **nonreplayed只表示未用于最近800步适配，并非原始模型从未见过。** 原始
  checkpoint来自更大训练池；全部24个记录均为合成train，不是新独立测试集。
- source_group均为 `crim13/021709_A25_Block22_BCfe1_t`。manifest有源视频帧号，
  没有已核实逐帧行为类别；不能声称覆盖了多少种已标注动作。
- 新16个渲染帧号（按源帧顺序）为：2、15、27、41、54、69、81、95、108、122、
  134、148、67、174、186、199。渲染帧号不严格对应源时间顺序，不能把此审计
  输入当成连续动画或时序训练。
- 固定原始相机实际顺序 `[2,0]`（侧、顶），输入768×432；逐场景原始双视角
  基线归一化。检查完整RGB/depth/mask/关键点读取及投影，最大GT投影误差
  **0.000131 px**。全部源文件、代码和权重哈希通过。
- 两个checkpoint均为eval/no_grad，原始或混合模型，不使用教师质量门控。
  匹配沿用评估的GT框/objectness成本，不使用GT关键点匹配。与上一阶段train-mode
  教师合格31个子集不同，本次报告全体32/64个instance-view，数值不可直接混用。

预先机制门槛：混合模型未回放Core23 NME > 已回放的1.15倍，并且未回放NME
> 原始模型的1.05倍，或检测召回下降超过.05；本轮第一项不满足。这个门槛用于
选择是否做下一实验，不是统计显著性检验，也不能证明增加覆盖永远没用。

## 同一匹配协议的结果

NME以GT框像素对角线归一化，全部有效标签参与；身体16和尾巴7分开。
下表均为全部视角、有效点加权；PCK含score≥.5、框IoU≥.5的检测门控。

| 指标 | 已回放8：原始→混合 | 未回放16：原始→混合 |
|---|---|---|
| 框IoU ↑ | .83607 → .88782 | .87316 → .84042 |
| 身体16 NME ↓ | .06348 → .06990 | .06337 → .07001 |
| 尾巴7 NME ↓ | .09103 → .08347 | .08249 → .08636 |
| Core23 NME ↓ | .07187 → .07403 | .06919 → .07499 |
| Core23检测PCK ↑ | .75679 → .75679 | .79144 → .76223 |
| 检测召回 ↑ | 31/32 → 32/32 | 64/64 → 64/64 |

已回放姿态的框/尾巴适配有收益，而未回放这两项略退化，因此**存在部分覆盖
差异，不能说覆盖毫无影响**；但身体误差在两组都约.070，主问题不局限于未回放。
未回放Core23相对原始退化8.38%，身体15/16姿态变差、尾巴12/16变差。
已回放身体4/8改善、尾巴6/8改善；均值变化和改善姿态数不必同向。

未回放的侧/顶身体NME：原始 .06570/.06103，混合 .07201/.06801；不是单一
视角独有的问题。原始与混合在这里所有实例均通过检测门槛，PCK下降来自定位，
不能通过降低检测阈值补救。此判断不替代旧开发源上的框IoU漏检结论。
