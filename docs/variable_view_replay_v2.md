# 1–N 视角：回放保留能力对照 V2

2026-09-10，用户授权继续自主循环。V1 已完成，固定相机对能力下降；
本轮不直接增加同分布训练，而检验混合回放能否缓解遗忘。

## 锁定设计

- 从原 768 checkpoint 相同初始化；冻结 encoder，深度与实例关键点监督保持不变。
- 两组各 800 步，学习率 3e-5。控制组为打乱日程的双鼠 1–4 视角；
  回放组 50% 与控制组完全相同的可变视角样本、25% 双鼠原固定对、
  25% 单鼠原相机对。每 16 步内交错均衡的视角数，不按每个姿态访问次数形成长区块。
- 双鼠使用原训练 session 的 32 姿态；单鼠分别取原训练来源
  moseq_sample10、mouse_climb_wall_91 各 16 姿态。
- 开发评估：沿用 V1 的 8 双鼠姿态 × V1/V2/V3/V4/固定对，另加原验证
  mouse_wash_face_91 的全部 16 姿态原相机对。所有来源与训练分离，但不是独立测试。
- 保持 768 长边、原宽高比；方形单鼠为 768×768，双鼠为 768×432。
  token 数按实际每条输入宽高计算。等更新，不是等图像、等算力或等双鼠曝光。
- 所有保留门槛参照**原始 checkpoint**：固定对与单鼠 NME 不劣化超过 5%，
  检测感知 PCK 不下降超过 3 个百分点；各组身体深度 AbsRel 不劣化超过 10%。
  V1/V3/V4 NME 至少改善 10%。不自动推广生产。

使用独立脚本保留 V1 已锁定代码、输出与可复核哈希。新脚本复用其经过检验的
训练流程，变更仅为日程、回放来源、评估来源及真实 token 计数。
内存特征 LRU 上限 32 GiB，无新增磁盘特征缓存，单轮最长两小时。
原数据、生产权重不变；输出 output/variable_view_replay_v2/。

## 自动决策与接续

现有 heartbeat 重新启用。每轮先核验状态、进程与锁；运行期间不改锁定代码，
不并行抢占 GPU，不重启旧 failed/completed 目录。无可行动变化保持安静。

V2 完成后：检验 checkpoint 重载、冻结 encoder、协议和数据哈希、实际
图像/token/来源/视角预算；查看曲线与最优/最差双鼠和单鼠图像，运行回归测试。
结果写入本文。最多再自主执行两个有界后续阶段，每阶段不超过 3 组×1,200 步、
最多 2 小时；每阶段启动前写定配置与判定门槛，保持数据来源划分与 768 分辨率。

若保留能力通过，优先做新种子复验与按视角的几何诊断，而不是立即扩大模型；
若失败，依据是姿态回退还是深度/共享特征漂移，选择单因素调整学习率、
回放比例或冻结范围做对照。不得把失败仅归因于步数不足。两轮无明确改善、
重复实现失败、资源不足或需要外部权限时停止训练并报告；无需为日常实验选择再询问用户。
不自动下载、删除数据、覆盖生产权重、推送 Git；不把单视角三角化或开发集
GT 辅助关联宣称为可部署的 3D 泛化能力。

当前：已完成协议准备（722 个精确子集/顺序记录），确认训练与开发来源完全分离，
并以 PID 219628 在 WSL 后台启动。现有每 10 分钟 heartbeat 已恢复为 ACTIVE。
新增 3 项调度/门槛测试通过；总回归通过 108 项（96 单元、7 头部/几何、5 loader）。

完成后的验收命令：

## 完成结果与自主接续（2026-09-10）

两组共 1,600 步，487.25 秒完成，运行锁释放、GPU 空闲；88 个来源场景哈希、
原权重/encoder、锁定代码、实际训练日程、保存张量与重载均核验通过。
原模型双鼠指标与 V1 初始评估一致。

回放组通过 12/13 门槛，唯一失败为原双鼠固定对 NME 上升 15.22%（门槛 5%）。
固定对 PCK 仅下降 0.68 个百分点，明显小于纯可变组下降的 8.56 个百分点。
回放的所有深度门槛通过：固定对 AbsRel 0.026271→0.023101，
单鼠 0.089309→0.084675。**PCK 保留不代表所有点精度保留**，不推广生产。

纯可变组单鼠反而改善更多；不能把“加入单鼠回放”先验认定为总是更好。
两组相同更新数但纯可变有更多双鼠曝光：2,000 图像/2,592,000 patch tokens，
回放 1,800 图像/2,635,200 tokens（方形样本使图少但 token 略多）。
训练分别 243.23/183.02 秒，显存峰值约 7.48 GiB。
