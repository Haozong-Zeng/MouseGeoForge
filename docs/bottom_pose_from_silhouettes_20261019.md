仅 CPU 几何求解；新增模型推理和训练更新均为 0。使用缓存的发布模型背景置灰预测作为旋转初值。侧视 K/E 为合成真值或真实标定；身体轮廓为渲染真值或人工确认，因此是 oracle 输入诊断，不能当成全自动未知装置成绩。没有使用底视真值初始化或拟合；底视标定只在求解后评分及检查固定装置的坐标一致性。

## 修正及撤回

1. **统一坐标系。** ClimbWall 与 MoSeq 的世界原点不同，相机中心整体相差约 25.98。旧两个脚本把六帧当成一个世界坐标系中的固定底视相机，真值残差又复用了最后一帧位姿。现在逐帧使用 `X_ref = R_ref (X_world - C_ref)`，同步变换所有相机与 up，在该坐标系中重建外壳、联合拟合。参考侧视 ID 确定性选择；变换后检查装置相对位姿不变。
2. **无效切线不再记零损失。** 极点位于轮廓内部、零基线或退化极线均视为无效。无效初值直接失败；无效试探保留固定四维残差并受非零惩罚；无效终点拒收、记录失败状态及最优有效迭代，不删除约束。84 个 frontier 拟合终点全部成功，最终无效约束为 0。本轮数据没有触发无效试探，保护逻辑由独立 CPU 反例覆盖。
3. **固定方位变体与旧数值。** 此变体准确说是禁用绕先验 up 的旋转分量，不是固定某个欧拉角；去掉原来未使用的第六优化参数。旧 hull 固定方位中位数实际为 **6.73°**，旧文 5.4° 为误抄。为隔离本次修复，hull 历史 `K[:2] *= scale` 缩放约定保持不变，尚有亚像素 resize 主点偏差。
4. **选帧与初值范围明确。** 默认均匀选帧，仅用所选帧构造旋转初值。旧 36 帧是排序前 36 帧（AZR2L2 25 + FR2 11，无 FR3），却用了全部 71 帧初始化；仅保留为历史复现。71 组中 25 组有 4 个有效侧视、46 组有 6 个；旧 36 组/全部 71 组分别有 166/376 对约束。
5. **撤回过强结论。** “两个侧视、六帧不可辨识”和“20 帧以上保证 1–2.5°”均撤回。拟合残差低于真值不证明不可辨识；残差中位数也不是求解器最小化的 soft-L1 总目标。旧随机子集无完整记录，本轮采用新固定种子重新测量，不声称复原旧数值。

极线相切参考 [Sinha、Pollefeys、McMillan：Camera Network Calibration from Dynamic Silhouettes](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/07/SinhaCVPR2004.pdf)。本文实现仅验证已知侧视外参下的底视求解，不等同于论文完整的未知相机网络标定流程。

## 复现与验收

依赖 Python、NumPy、SciPy、OpenCV。入口只读已有数据及缓存预测，不加载神经网络；输出采用排他创建，不覆盖历史记录。目录选择一个新路径。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=.venv-vggt-omega-eval/bin/python
$PY -m unittest discover -s tests -p test_bottom_pose_silhouettes_20261019.py -v
$PY tools/validate_bottom_pose_silhouettes_20261019.py --part frontier --output-dir output/silhouette_reproduction
$PY tools/validate_bottom_pose_silhouettes_20261019.py --part hull --output-dir output/silhouette_reproduction
```

单次随机复测：

```bash
$PY tools/bottom_pose_frontier_20261019.py --data real --selection random --max-frames 24 --seed 20261019 --prior-scope selected --output output/silhouette_reproduction/single_repeat.json
```

对应 hull CLI 支持相同选择参数；合成使用 `--data synthetic`。56 案例完成后用 `summarize_bottom_pose_silhouettes_20261019.py --input-dir <目录>` 检查案例、当前代码与输入哈希；frontier 入口还会自动生成独立重复验证的 `deterministic_repeat.json`，汇总会验证该记录。不加参数只打印摘要；显式加 `--write-compact` 才写紧凑数据。

9 项 CPU 回归测试通过，覆盖坐标/投影不变性、极线公式、真值切线、零基线、无效初值拒收、无效候选惩罚/终点拒收、五参数变体、固定种子与子集初值隔离、输出防覆盖。另独立重跑随机 24 帧 seed20261019，帧清单、初值帧清单一致，完整/限制绕 up 两种模式的 R/C 最大绝对差均为 0。求解器收敛不等于外参准确。

## 后续路径（仅计划，不启动训练）

1. 第一阶段保持已知侧视 K/E，先评自动掩码和轮廓截断敏感性，再测侧视旋转、中心、K 的受控扰动；不要因旧合成失败结论直接增加帧数和侧视数。
2. 未标定路线必须显式提供侧视相对旋转、相机中心/平移方向及内参估计。up/旋转加一个已知距离只确定部分自由度，不能恢复所有相机中心；若使用 VGGT 平移，应验证方向、共同 gauge 与退化基线。
3. 本轮为事后开发诊断，非密封确认或自动定位成绩，不据此晋级模型。L0、P0/P1、G0/G1、关键点训练及集群任务均未启动；历史自动化继续暂停。
