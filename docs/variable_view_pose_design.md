# 可变视角统一模型：1 到 N 个视角

2026-09-10。用户明确目标：**同一个模型灵活处理单视角到多个视角**，而不是分别制作
单视角、双视角和四视角模型。该能力应成为长期基础接口，原来的八组消融共用同一视角
采样日程，不必将视角数再增加为一个独立架构开关。

## 输出约定与当前边界

| 输入/观测情况 | 应提供的输出 | 不能混淆的概念 |
| --- | --- | --- |
| 1 个真实视角 | 每个实例完整 2D 骨架、可见性、不确定性、深度预测 | 不可称为三角化得到的 3D |
| ≥2 个视角，关联和几何可用 | 上述逐视角输出，以及受有效性检查约束的三角化 3D | 两视角不具备任意剔除一个异常观测的冗余 |
| ≥3 个有效观测 | 可进一步检查跨视角一致性和异常值 | 输入图像数不等于最终内点数 |
| 单视角或融合失败但仍需完整 3D | 后续学习式 3D 提升/骨架先验预测，必须独立标记来源及置信度 | 当前还没有这个独立的单目关节 3D 分支 |

不可见但有可靠投影标签的关键点仍参与二维坐标训练。单视角不是“只输出可见点”。
深度是表面深度；不能直接将表面反投影当作内部关节中心。
单目尺度存在歧义；没有可靠标定/尺度来源时，不得将相对深度标成准确毫米值。

## 已实现：可变输入基础设施

- `DepthPoseModel.forward` 接收 `[B,V,3,H,W]`，明确拒绝空视角。
  模型参数没有固定四视角上限；实际可用数量受显存、分辨率和训练覆盖限制。
- `forward_ragged([images_1, images_2, ...])` 支持不同场景具有不同真实 V，
  每个元素为 `[V,3,H,W]`，返回对应独立结果。没有补零图或重复图。
  当前是逐场景前向的正确性优先实现，不声称已实现高效 padded attention；
  高吞吐训练应按 V、H、W 分桶。
- `mousegeoforge/view_sampling.py`：按日程均衡覆盖 `1..min(可用相机数,资源上限)`，
  每次不放回地抽取真实相机并随机化顺序/首视角。可用相机 ID 不必从 0 连续编号。
  同一可用相机集合的完整采样周期计数均衡；不同来源的总量仍由外层场景采样器控制。
- 显式 subset record 保留原场景和 split，不会自己把验证/开发场景加入训练。
- `view_cache_key` 将 RGB 版本、编码器哈希、预处理、物理相机子集及顺序绑定。
  **不能截取四视角的上下文特征，冒充单/双视角编码结果。**
  该缓存标识工具已用于功能 smoke；旧全量训练器尚未接入动态采样缓存调度。
- Blender loader 增加可选 `normalization_scale_override`；旧调用默认不变。
  实验加载入口显式支持 `num_views=1`，但要求提供场景级尺度，防止单视角时突然
  从基线归一化退回原始毫米深度。

没有复制图像凑 V，也没有把多个时间点自动当作同时刻的多视角。
后续时序输入的 T 与视角 V 必须分开，当前模型仍是帧级模型。

## 训练要求

1. 先按源视频/动物划分训练与验证，再在同一场景内抽取相机，禁止借相机划分泄漏同一姿态。
2. 训练必须包含 **V=1、2、3、4**，并覆盖不同相机组合及首视角；当前素材最多四机，
   是第一阶段的数据上限，不是模型写死的架构上限。
3. 子集和顺序在 encoder 之前决定。缓存可选择有限、可复现的日程，或按需计算并管理
   缓存容量；不能将缓存的四视角 token 任意删几个就当作视角 dropout。
4. 检测、有效二维坐标、已知可见性、有效深度监督对所有 V 适用。
   三角化 3D/重投影损失仅在同一实例拥有足够有效相机观测时计算。
   当前几何损失对单视角返回零项和零有效计数，不伪造三维点。
5. 不同 V 的场景按场景平均损失后聚合；不能让四视角场景因图像更多而自动拥有四倍权重。
   记录有效标注数、图像数、编码 token、更新步数和 GPU 时间。
6. 同一场景所有子集使用同一标注尺度。可由已知固定 rig 的完整标定确定并写入元数据；
   真正只有一台相机的数据需要明确的物理单位/固定尺度配置，不依赖不存在的第二相机。
   对未知标定的部署输入，不可假定训练集 rig 尺度已知。

此前固定 `[0,2]` 双鼠相机对不能满足这个目标；只增加该相机对训练步数也不能替代
单视角、其他相机及可变上下文的覆盖。

## 已完成的验证

新增 9 项单元测试，全部回归 **100 项通过**（88 unittest + 7 头/几何 + 5 loader fixture）：

- 缩小模型 V=1/2/3/4/6 前向、不同 V 的独立 ragged 输出与单独调用一致；
- 单视角坐标/深度反向传播，冻结 encoder 不产生梯度；
- 视角数量计数均衡、相机组合和首视角覆盖、不放回采样、确定性；
- 缓存身份对子集/顺序/RGB/编码器改变敏感；
- 单视角不生成伪三角化，相关几何损失有效计数为 0；
- 视角减少时归一化尺度及世界坐标标签保持一致。

完整现有 checkpoint 在一帧真实 Blender 数据文件上完成 V=1/2/3/4 的 768×432 GPU 推理。
这里“真实数据文件”指实际加载的合成数据，不是实拍动物视频。

| V | 物理相机 ID 顺序 | 有效二维标签数 | 关键点输出形状 |
| --- | --- | ---: | --- |
| 1 | `[0]` | 46 | `[1,1,6,23,2]` |
| 2 | `[3,0]` | 92 | `[1,2,6,23,2]` |
| 3 | `[2,3,1]` | 138 | `[1,3,6,23,2]` |
| 4 | `[2,0,1,3]` | 184 | `[1,4,6,23,2]` |

6 是检测 query 数，不代表有六只鼠；这一帧有两个已标注实例。
四次调用使用同一场景尺度 461.448883 mm，世界标签和共享相机的归一化深度一致。
所有缓存预测有限。**这是功能检查，不是可变视角精度提升的证据**；现有权重没有微调。
