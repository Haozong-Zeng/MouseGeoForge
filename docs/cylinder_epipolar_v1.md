# Cylinder 身体极线约束 V1

2026-09-11，自主循环阶段8。固定混合训练日程，仅增加身体16的极线约束。
预检、800步候选及完整验收已完成。几何有小幅改善，但未达到预设实质改善条件，
双鼠保留退化；不推广生产模型，不直接放大极线权重。

## 损失规范

独立helper `mousegeoforge/epipolar_supervision.py`，不修改历史锁定模型/loss。
从已知OpenCV世界到相机K/E计算视角对的fundamental matrix；不让标定参与反传。
预测normalized UV先转像素，计算有符号Sampson距离，除以图像对角线。
对该残差使用smooth-L1 beta=.01，权重1。每个视角对在有效身体点上平均，
然后按视角对平均，最后按实例平均，避免某只鼠/某组视角的点更多而占据更大权重。

复用**同一次**原始Hungarian匹配，以持久instance_id连接同一只鼠，不能以query索引
跨视角直接配对。排除尾巴7:14，仅新增身体16约束；原Core23监督和历史门槛保留。
包含有标签的遮挡点；未知标定、缺标签、未知ID、单视图不增加约束，V1返回可微0。
同位相机不形成有效极线对；同一视角重复实例ID明确报错。
不按当前预测置信度或三角化是否成功筛掉最难点，也不向网络输入GT关键点/标定。
GT继续用于原监督和训练实例匹配；新增项只约束预测坐标与已知相机的几何关系。
原2D定位监督保留，防止仅满足极线但不对应真实关节的退化解。

## 决定与后续边界

本项计为连续第1项未达实质改善的方法，不能把几何小收益当成通过既定目标。
保留极线约束作为待复验方向，暂不继续扫描权重、延长训练或叠加其他loss。
下一项先做**双鼠回放保持原模型输出**的训练侧可行性检查，独立于极线项：
检查原始teacher在现有双鼠回放姿态的框/身体/尾巴质量和匹配稳定性，再决定是否
采用一次受限的框＋关键点保持实验；关闭组仍使用混合训练，不从此ON权重续训。

预检只用已有8个双鼠回放训练姿态，teacher为原始checkpoint、student为混合checkpoint。
按同一GT实例身份分别匹配teacher/student，不假设query序号相同；只保留teacher
objectness≥.5、GT框IoU≥.5的实例和已有有效关键点标签。
拟议额外项为normalized box与Core23 xy的smooth-L1(beta=.01)按实例平均之和、权重1，
只作用于双鼠回放步骤，原GT监督保留，teacher停止梯度，不增加深度/几何/温度机制。
先要求teacher在被选训练实例上框IoU和body/tail NME不劣于student，再核验匹配、
零权重逐值一致、原始初始化时保持项为0、梯度有限；混合checkpoint处辅助梯度
中位范数≤原总任务25%，不按开发结果调参。不满足则不启动训练，记录证据。
若通过，再锁定同混合800步日程/原始初始化的唯一候选，生产保持不变。
若下一训练方法同样无实质改善，达到连续2项后暂停循环总结，不无限添加小loss。
