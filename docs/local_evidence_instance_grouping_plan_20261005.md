2. **1.5–5小时：实现并验证最小分组模型。** 首选共享可训练HRNet局部证据+预测中心/实例条件分组，含null/拒绝输出；对照独立打分或不使用实例内交互的同类解码器，确保两臂都输出实例姿态，局部头单独作为覆盖参考而不是不公平最终基线。相同原mixed800初始化、相同图像/增强/优化步数/目标与随机种子17；额外参数、计算如实列出。先做小样本拟合及640步预检，必须确认梯度、实例置换、缺失点、第二鼠不是背景、RGB-only前向、默认关闭兼容。中心监督无法可靠定义则改用不依赖真实中心标签的实例query分组，并记录原因，不伪造中心真值。
