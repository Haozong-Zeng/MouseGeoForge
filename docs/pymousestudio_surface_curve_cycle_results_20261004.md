# PyMouseStudio 数据整理与背侧体表线实验结果

本轮从 2026 年 10 月 3 日 20:35 UTC 开始，完成真实标注有效版本、最终 Blender 工程整理、新合成数据集和背侧体表线监督的小规模探索。结论是：数据交付可用，但尚无可替换正式模型的曲线 checkpoint。空间热图读出明显优于本轮的全局坐标读出；直接放宽背部点损失没有稳定收益。下一步优先建立少量、独立复核的真实体表线参考，而不是继续增加相近损失变体或把拟合结果升级为真值。

这是固定开发划分上的探索记录，不是最终独立测试。Core23 原有语义不变；体表线不等于内部脊柱、侧面剪影或 mask 中轴。原始标注没有被模型预测覆盖。

## 实验设计与边界

主要诊断固定 768 长边、冻结特征提取器，用相同初始化、批次规则和步数做配对。较多后续实验只是轻量头部探针，而非完整模型端到端训练；它们使用 GT 框或匹配辅助的实例查询关联，不能解释为完整多鼠检测性能。

合成紧凑输入共 326 个实例视角观测，其中训练 238、验证 88；训练覆盖 89 个姿态，验证为 30 个姿态，包含留出的 CRIM13 视频源和 WashFace 动作。仍共享美术资产，不是完全外部泛化测试。

真实小验证集固定为 8 组、48 图、58 个提供坐标的背部点。训练从 28 组 188 图扩展到 156 组 1043 图，验证不变。FR2 和 AZR2L2 曾用于渲染画风开发，不能称从未接触的外部测试。GR2、UR2、UR3 保持锁定，不作训练或选择依据；最终完整性审计只核对其文件哈希，不进行预测评估。

以下像素指标在 768 训练坐标系下计算。三个种子固定为 17、29、43；小样本三种子一致不等于统计显著。旧 checkpoint 和失败结果均保留，没有晋升正式模型。

## 多视角人工点歧义

使用固定标定做留一相机检查，并排除任何包含被留出图像的双视角特征上下文，避免图像泄漏。58 个背部点中 46 个满足几何条件。人工点之间的留一重投影均值为 27.30 px；模型三角化后的对应误差为 35.69–41.24 px，不能作为更准确 3D 真值。

人工鼻尖留一误差均值约 6.70 px，四足约 7.78–13.68 px，背部 06、07 分别约 27.54、26.93 px。进一步匹配完全相同的留出帧和源相机组合，30 对背部与鼻尖案例分别为 31.70 和 10.73 px。这支持背部对应定义存在额外歧义，但不能唯一排除局部标定、折射或遮挡，更不是人类标注误差下限。足部也存在反例，不能一概当作准确锚点。

详见 `manual_multiview_controls_v1` 和 `real_point_multiview_audit_v1`。它们只输出审计诊断，不写回数据集 3D 标签。

## 已知体表线上的受控扰动

另设虚拟 A、B 为合成体表线物质参数 0.30、0.70，不重定义 Core23 的 06、07。训练标签加入固定的沿线参数扰动 ±0.15 和法向 2 px 高斯扰动，平均像素偏移约 8.66；验证标签保持干净。这个核是人为压力测试，并非测得的真实标注分布。前向只接收图像特征及原模型粗预测，GT 曲线只用于监督和评价。

每组 2400 步，配对结果如下，数值顺序均为种子 17、29、43 的验证锚点均值误差。

| 监督方式 | 验证误差 px |
| --- | --- |
| 干净点监督参考 | 22.62 / 26.07 / 23.46 |
| 带噪点严格监督 | 21.94 / 26.38 / 25.55 |
| 带噪点加沿弦方向宽容 | 24.85 / 23.50 / 25.94 |
| 使用真实切线的宽容监督诊断 | 28.48 / 26.39 / 27.86 |
| 严格点加已知曲线几何辅助 | 21.69 / 25.25 / 24.72 |
| 宽容点加已知曲线几何辅助 | 23.34 / 24.86 / 25.12 |

严格点加曲线辅助改善约 0.25、1.13、0.83 px，是有限的正向信号；曲线距离和最近物质参数误差并非每个种子都改善。可视化中 WashFace 的 B 点仍偏向躯干内部。沿线宽容自身无稳定收益，即使真实切线也未解决；损失强度同时变化，因此不能把失败唯一归因于方向定义。

干净参考训练误差只有 3.35–3.44 px，而验证仍为 22–26 px，提示跨姿态泛化也是主要问题。不能仅继续增加 epoch 后宣称标签问题已解决。输出在 `controlled_back_noise_probe_v1`、`controlled_back_curve_aux_v1`；后一组的严格点基线三种子均精确复现前一组。

## 下一步真实曲线复核建议

建议先试标 12–20 个现有开发集同步组，不动锁定测试视频。覆盖四足、抬头、攀爬、弯身、部分遮挡，包含常规例子和本轮背部与鼻尖足部不一致的例子。每组提供全部同步相机、原分辨率图和合成定义参考。数量是待确认的试点建议，本轮没有向合作者发送任务或创建新的正式标注批次。

两名标注者先独立描线再复核。要求如下：

- 只描可辨认的背侧体表中线，不猜椎骨位置，不把 mask 中轴或剪影自动当中线。
- 可见部分用有序折线；遮挡处断开，记录可见区间和是否只能判断剪影。不强行连接缺失端点。
- 颈背过渡和尾根无法确认时分别标记端点未知。底视不能直接给不可见背侧线补坐标。
- 06、07 原点另存，不要求落在曲线任意固定比例。新曲线是附加标注，不覆盖旧点。
- 记录相机、原始帧、标注者、定义版本、轮廓类型及可见性；原始折线、复核折线、模型拟合版本分开保存。

用双人线的法向差异、端点分歧、可见区间和留一相机预测共同评估，而不是只评价拟合用相机的重投影。先确定哪些视角确实观察到同一条物质线，再考虑共享三维曲线拟合。各视角独立等弧长采样后直接三角化仍不可用。

训练方向保留两层：合成数据用已知体表几何与固定物质点强监督；真实稀疏旧点保持来源和不确定性，只有补标且可靠的片段才引入片段曲线监督。空间读出可以进入下一轮完整 Core23 对照，但应保持实例关联、可见性和默认关闭兼容，并单独验证一到多视角。暂不加入时序，以免与本轮曲线监督混淆。
