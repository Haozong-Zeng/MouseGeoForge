# PyMouseStudio：尾部 mask 的 DLC 辅助修正

2026-09-12。范围仅 AZL3 的780–811帧、7视角。原始视频、旧重建和标注包均保留。

## 原因与DLC适用范围

对矫正后的source31尾点逐帧核对，在likelihood≥0.8、至少3路视角、15px内几何共识门限下：

|点|32帧中通过鲁棒三角化的帧数|
|---|---:|
|tail_root|32|
|tail_0|28|
|tail_1 / tail_2 / tail_3 / tail_4|各0|
|tail_end|2（783、796）|

一些尾尖虽有较高DLC置信度，各相机仍落在不同尾段，不能强行拟合完整3D尾曲线。
这些几何通过门限的点也仍是模型预测，不是人工GT。

直接原因之一是旧底视SAM2使用当前3D hull的外接框：hull尾尖先丢失，提示框跟着缩短，
再造成SAM2尾尖丢失。第796帧旧框ymax约1057px，而通过几何检查的尾尖投影为
约(354.1,1137.6)px，落在旧框之外。这说明仅改变多视角投票无法修复输入mask本身的截断。

## 尝试与结果

1. `tail_dlc_audit_v1/`：实际尾点/置信度/侧面mask叠加及三角化记录。
2. `reconstruction_tail_guarded_v1/`：只用可靠尾根定位原mask中的细尾区域，尾部放宽至
   至少3路侧视支持并要求宽基线、3D连通。只能补小缺口，不能补回旧SAM2已经漏掉的尾尖。
   对旧输入mask的覆盖率很高也不说明尾巴完整，此路线不足。
3. `tail_dlc_video_masks_v1/`：使用第783、796帧通过几何检查的尾根/近端/尾尖作为SAM2
   视频提示，扩大到底部场地中实际尾巴活动区域的框，不再依赖逐帧残缺hull框。
   正反向跟踪覆盖32帧。完整跟踪mask有一些玻璃假阳性，因此只取尾根后方长而细的图像分割区域。
4. **`reconstruction_tail_guarded_v2/`：本轮保留的修正候选。** 原有body hull不变，
   只在上述新尾部ROI补入同时满足以下条件的体素：
   - 底视图像分割支持；
   - 至少3/6侧视mask支持，且至少一对支持相机对尾根的夹角≥60度；
   - 与已有3D占据形状连通，不独立生成漂浮管线。
   不插值低置信DLC中间尾点，不凭一条2D线编造深度。

最终栅格化限制在新增尾部的投影范围；底视ROI外深度保留旧值，避免栅格化器的全局
中位距离改变投影半径而影响整个鼠体。输出仍为原尺寸1080×1200、毫米相机Z、float32 PFM。
每个视角另存 `tail_changed_pixels/`，将来可单独审核/降权新增区域。

## 视觉与验证

检查780、796、811帧的底视对照和七视角深度：尾端较旧版更完整、更连贯，
第796、811帧原先明显截短的部分已补回。第796帧局部仍有细小反光粘连和毛刺，
不能声称已得到精确表面或全部问题解决。

32帧、224张新PFM及mask全部检查尺寸、有限非负深度、mask/depth一致性；
底视尾ROI外逐像素不变；所有视角丢失旧有效前景像素数为0。
6项针对性unittest通过（细尾ROI、无尾不造线、空mask、三角化、畸变点、PFM方向）。

以**新的跟踪尾部mask**为参照，尾部覆盖率均值约从76.1%到99.2%；
这是参与重建的输入mask覆盖率，不是人工IoU、独立准确率或深度误差。
人工标注包的ZIP哈希保持不变。所有新增结果仍 `training_supervision_enabled=false`。

本机SAM2可选CUDA连通区域/孔洞后处理扩展 `_C` 不可用，推理正常完成但跳过该后处理；
本轮未安装或修改依赖。剩余小片段需要图像/时序复核，不能靠伪标签分数自动宣告正确。

## 检查入口

目录均相对于 `dataset/PyMouseStudio/sessions/AZL3/`：

- `reconstruction_tail_guarded_v2/review/tail_repair_comparison_h264.mp4`：旧版橙色、新版绿色、
  七视角新深度。32帧以8fps慢放，源帧率52fps。
- `reconstruction_tail_guarded_v2/review/bottom_tail_000796.png` 与 `000811.png`：底视对照。
- `reconstruction_tail_guarded_v2/verification.json`：可机读校验与限制。
- `tail_dlc_video_masks_v1/review/`：跟踪mask及仅尾部合并的中间结果，不作为人工标注。

后续建议：先复核几帧尾尖和玻璃交界处的真实mask，再决定是否推广到更长片段。
不要直接将低置信中间尾点接成曲线，更不要把本次输入mask自一致性指标当成真实精度。
