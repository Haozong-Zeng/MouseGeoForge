# 输入相关局部热图锐化：实验方案（2026-09-11）

## 动机与唯一机制

局部余弦logits直接softmax时，实测熵约.96；已有只读统一T=8诊断改善底视但
伤害双鼠。只增加一个从当前关键点token预测的有界logit乘数，允许不同图像、
实例和关节采取不同锐度。输入只来自模型token，不使用相机类别、GT、源名称
或目标数量做路由；支持1–N视角及任意预测实例数。

定义 `scale=exp(clamp(linear(L2normalize(keypoint_token)), log(.5), log(8)))`。
新linear权重和bias全0，初始scale严格1；不改原始粗坐标、半径.1、8×8网格、
grid梯度路径、decoder/encoder结构和原loss。不是提高分辨率，也不声称解决窗外点。
保留所有Core23监督，不叠加极线/保持/粗辅助/深度联合/时序机制。

实现为独立实验安装器，不修改已锁定upstream头文件。重用原局部函数生成raw
logits，随后按相同offset重新softargmax；输出的local logits为实际缩放后值。
保存每实例/关键点scale用于审计，而不是只报告训练loss。

## 预检及训练约束

先用stage11的16个现有训练输入检查：初始全部输出与原模型逐值相同，全部
原参数的梯度在浮点容差1e-6内一致；新scale参数梯度有限非零，梯度中位范数
不超过原完整instance head范数25%。合成测试覆盖置换、边界、保存重载及scale1。
不以开发误差选择权重、学习率或初始化。

首轮仍使用source_mix同800步、原始权重初始化，旧参数lr=3e-6，新零初始化
scale线性层lr=3e-4（独立新层需要适应，预先固定，不扫描），AdamW其余参数不变。
800步OFF直接复用已完成source_mix，不重跑旧实验。比较相同88条、原17门槛及
深度/双鼠/粗细与窗口统计。新层初始零参数不与旧checkpoint结构哈希混为相同；
要核验旧参数投影哈希与所有初始预测严格相同。

用户已授权按收敛情况增加训练步数：若800步趋势及泛化尚有收益，可另锁定
等预算OFF/ON扩展，必须记录两组优化器恢复/重置策略，不能把新增步数当成
机制收益。扩展以800步为评估阶段，首轮累计上限3200步，若训练改善但主要
开发与保留持续退化则停止。不得覆盖800步历史结果，也不按开发集挑最佳checkpoint。
完整方法判断在预先声明的终点作出；若本方法也无实质改善，连续2项后暂停总结。
