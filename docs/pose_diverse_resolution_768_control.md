# Diverse400：512 → 768 分辨率对照

2026-09-10。按用户要求检查：扩大至 400 场景后，提高分辨率是否进一步改善双鼠。
基线为已验收的 `output/pose_diverse_core23_512_v1`，不是旧 64 场景模型。

## 固定协议

- 完全相同的 400 训练、32 验证场景及其顺序，原 64 训练子集仍单独复算。
- 长边 768：Homecage 输入 W×H=768×432，方形场景 768×768。
  从源 RGB/深度直接读取缩放，不放大 512 缓存；像素数为 512 版的 2.25 倍。
- 相同 seed17、新头初始化和原始 Omega 权重；不是从训练好的 512 checkpoint 续训。
- 冻结 encoder，重新提取 RGB 特征；相同相机 ID [0,2] 和实际视角顺序。
- 相同 15000 步、5000 步 LR=1e-4 后余弦至 1e-5、采样顺序、优化器及损失。
- bridge off；不加入 ROI、增强、时序、尾曲线、3D 损失、新数据源或真实图像。
- 等更新数、等 epoch，不是等计算量；初始化权重应一致，但初始预测/指标可因
  输入和 token 网格改变而不同，不要求跨分辨率初始指标相等。

输出单/双鼠分来源 NME、计漏检 PCK、检测、尾部、鼠体/全图深度误差。
固定终点验收，不用验证挑 checkpoint。视觉复核双鼠 40/98（训练）和
246/393（验证），与 512 Diverse400 对比；相机 2 为侧视，0 为顶视。

双鼠 NME 增加约 **20.1%**，计漏检 PCK 下降 **4.42 个百分点**；尾部 NME
由 0.1076 升至 0.1420。因此本次不能认为 768 更适合双鼠关键点任务。
单鼠 PCK 增加 **8.70 个百分点**，NME 略降，但召回降低、尾部误差增加，也非全项获益。

两组的鼠体和全图深度误差均下降，mask IoU 均增加；更细输入对稠密输出有收益，
但没有自然转化为双鼠姿态收益。深度和 mask 在各自输入网格计算，包含栅格精度与
边界采样变化，不把其收益解释为同一固定网格上的纯模型能力增益。
所有结果是固定 15k 终点，不挑验证最优步数；NME 无量纲，不是毫米误差。

### 固定困难帧视觉检查

已逐一检查两组 `seed17_off/diagnostic_visuals/` 下双鼠
`000040.png`、`000098.png`、`000246.png`、`000393.png` 对应的长文件名图片。
上行为 camera 2 侧视，下行为 camera 0 顶视；颜色是每图框匹配，不是跨帧身份。

- **训练40**：两版都能找到双鼠主体。768 顶视部分四肢比512稍展开，但依然
  偏窄；侧视举起的尾段未恢复到 GT 的高度，不能称姿态问题已修正。
- **训练98**：两版长轴位置大体正确；768 侧视部分四足分离较清楚，
  但顶视仍存在四肢向躯干中线收缩、尾部延伸不准，没有稳定的全身改善。
- **验证246**：两版仍能分别定位两只鼠，未恢复早期64场景模型的整簇串位。
  768 黑鼠尾部弯曲与局部四足有可见变化，但侧视棕鼠点簇仍偏短，
  不同部位有得有失，不能用这一帧宣称整体提升。
- **验证393**：768 顶视两只鼠四肢依旧贴近中轴，尾部明显偏短或偏直；
  侧视也偏紧凑。没有解决此前关心的四肢收缩和尾形问题。
- **深度**：768 多帧鼠体和尾部轮廓较清楚，与数值改善一致；墙/地边界仍有
  模糊、背景不均匀，不能等同于准确恢复四肢或骨骼深度。

### 结论与下一步建议

当前以双鼠关键点为优先目标，**保留512 Diverse400作为后续对照基线**，
768保留为稠密深度/mask收益参考，不覆盖旧模型。分辨率不是剩余问题的充分解法；
本轮不能证明具体瓶颈一定在编码器、实例头或监督方式，需独立消融。

下一步优先固定数据与512协议补配对种子，再做既定深度—关键点联合开/关；
若另测实例局部细化/ROI，必须单独成组，不与分辨率或损失一起改变。
更长训练可以作为独立预算实验，但不能以训练曲线下降代替验证收益。
这些均为建议，本轮未自动启动。仍只有单seed、一个双鼠训练来源、合成域验证，
没有真实域泛化或统计显著性结论。

验收时48项回归测试全部通过。源码/报告归档后暂停自动复查，
