## 尝试、失败与保留下来的证据

| 路线 | 观察 | 决策 |
| --- | --- | --- |
| mask参考框 | 框更能跟随鼠体，但关键点未变、重复槽仍在 | 只修框不能冒称修复姿态/多实例 |
| 全图热图/软mask先验 | 平移一致性可很高，但关节点容易一起吸向鼠体中心 | 否决直接argmax或mask先验替代 |
| 可学习空间分支与尺度相关可见热图监督 | 建立F；底视及若干保留指标改善 | 保留可复现研究参照 |
| 条件gate、只监督最终坐标 | 普通侧视/双鼠保留代价未消除 | 不部署、不靠挑checkpoint掩盖 |
| ROI放大/仅居中 | 放大不是单一答案；旧绝对坐标路径会拖累居中后的预测 | 位置依赖不能全归咎低分辨率 |
| 大范围位置增强 | 平移更稳，普通姿态退化 | 停止继续扫增强强度/比例 |
| 训练匹配修复 | 宽增强双鼠确有box槽互换；mask强冲突修复后泛化未恢复 | 错误已定位，但不是完整病因 |
| 26%混合宽增强 | 恢复部分普通保留，仍有位置稳定性取舍 | 不增加步数赌泛化 |
| 身体/尾巴梯度 | mixed400整体余弦+.919；双鼠局部冲突率4.04% | 不支持尾巴冲突是当前主要原因 |
| 同容量输出起点对照 | A的单底和平移收益明确，侧/双鼠退化 | 不全局替换，不按相机名称拼最优分支 |
| 独立/联合编码 | 作用依赖读出和视角；无全局赢家 | 不直接关闭joint |
| 已知K/E三角化 | 标定正确仍存在低覆盖/语义误差 | 几何约束不能替代准确2D解剖证据 |

工程负结果同样保留：早期历史浮点回放差异、旧CUDA采样反传非确定性、world轴误切片的失败预检等均未抹除。后续采用冻结特征的确定性局部采样，多组控制权重与AdamW逐位复现；不能倒推早期全部试验也逐位确定。

## 几何验证的边界

固定32条合成记录，GT最大投影误差.000161px，支持GT三角化的归一化误差最大6.03e−7。无坐标/尺度故障证据。

使用GT-mask辅助逐实例跨视图关联，**不是可部署的多鼠身份关联系统**。8条单底记录的128个body点明确insufficient_views；不补零、不虚构单目三角化。其余24条共512点，固定8px重投影、3px Huber、1度射线门槛，六臂共同支持集上比较误差。

联合编码F/B/A：双鼠共同126点误差7.97/9.71/10.64mm，覆盖80.08/79.69/78.12%；单鼠双侧的A覆盖仅51.56%，不能因只剩较容易点而宣称准确。两侧底的B覆盖100%，共同104点归一化误差.13712，F为.15128、A为.15345，但其他组不能推广。WashFace以Blender world units报告，不与双鼠毫米混算。

## 下一步优先级

1. 等真实人工关键点/分割标注返回后，核对Core23左右侧、遮挡/未标记语义和去畸变坐标；按独立视频源/动作划分训练与验证，继续锁住既定真实留出。不能把DLC或伪mask当人工GT。
2. 优先验证解剖特异性与合成到真实的差异，而不是再增加当前32场景小残差的步数。真实四足误差尚未被测量，不能依据一致性宣布真实最优。
3. 下一次训练应预注册一个主要变量：例如可训练的实例局部视觉解码，与等容量全图读出对照；保留可见/遮挡监督，避免用mask硬裁不可见关节。F/B/A作为固定研究对照，勿按开发结果手工拼每视图最优模型。
4. 标定感知晚融合可继续，但需同时做真实可用的多实例跨视图关联、校准后的定位不确定性、支持/拒绝率。1视图退回明确的2D或单目预测路径，不伪称三角化3D；2视图不冒称具备任意离群点排除冗余。
5. 尾巴可按用户既定意图作为多鼠可选任务；目前无证据说明关闭尾巴能解决身体定位，不应优先投入复杂曲线/时序分支来掩盖静态错误。
