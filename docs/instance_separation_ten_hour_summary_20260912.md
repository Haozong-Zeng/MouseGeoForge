## 下一轮建议（仅记录，尚未启动）

1. 独立源验证先行。88开发集已被多轮用于方向选择，不能当作未见测试集。
   在现有授权数据范围内按源动作/视频分组预注册新验证，不因帧号不同就
   当成独立源；真实Cylinder缺失，不能声称解决真实底视域差异。
2. 保留原query与中心候选的互补初始化，增加可学习的box residual和实例
   解码，而非永远固定框只改objectness。首先冻结VGGT与深度路径，保留
   768及1–N视角；OFF兼容、有限梯度、源哈希与深度输出不变先过预检。
3. 先独立做“可学习框细化开/关”的同预算对照；训练匹配考虑当前分类和
   L1/GIoU，之后再单独比较质量感知分类损失。不要一次改匹配、loss、数据
   与模型容量，也不要将GT覆盖上限当推理规则。研究依据及官方源码链接见
   上述监督审计文档；这些是借鉴，不是已复现DINO/RT-DETR。
4. 候选真正改善后再接实例内关键点解码。中心候选不能直接借用另一query
   的关键点/mask；明确候选与实例身份、可见性和多视角融合绑定。届时重新
   报告身体/尾巴坐标、检测感知PCK、mask重复和原17项保留门槛，实质收益
   才做seed29，不把box-only指标宣称为完整姿态模型提升。
