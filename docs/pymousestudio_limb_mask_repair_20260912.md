# PyMouseStudio 腿部断裂排查与局部修补

## 结论与范围

在 AZL3 原始帧 780–811（32 个连续帧）、7 个视角上完成独立修补版本。未覆盖尾巴修补版、原始数据或标注包；未启动训练或全数据集导出。

输出根目录：`dataset/PyMouseStudio/sessions/AZL3/reconstruction_limb_guarded_v1/`。

## 视觉诊断

- 第 811 帧底部 A 的旧单帧 SAM2 分割明显漏掉画面左下方的后爪；此前时序 SAM2 已找回该爪，但上一轮只合并尾巴区域，未更改身体/四肢分割。
- 底部 mask 作为硬性体素约束，导致侧面 B/C/D/F/G 中实际可见的腿中段被裁掉，留下与身体分离的足部。这不是通过平滑深度图可以根治的问题。
- 对照原始 RGB、提供的侧面 mask、旧重建与新重建，第 811 帧的后腿连接明显恢复；802、803、808 帧也有类似改善。腿间的真实背景未被整体填平。
- 780、796 等帧腿部原本相对完整，改动很小；796 D 的剩余连通分量不代表后腿仍断裂，部分来自其他部位。
- 检查了 780、791、796、802、803、808、809、810、811 的全视角图及 811 的原分辨率腿部放大图。810–811 仍有头部分割缺失，与本轮腿部修补无关，保留并记录。

## 方法

1. 使用 source31 的 5–18 号四肢点；保持原始点语义，不把脚趾、踝、肘混同 Core23。DLC likelihood ≥0.8、至少 3 个几何一致视角、重投影阈值 15 px 的点才用于定位。高 likelihood 本身不代表可见或正确。
2. 将可靠 3D 点投影到底部，90 px 半径只定义局部搜索区域，**不画骨骼线、曲线或填补背景**。
3. 只从已有时序 SAM2 分割中取该区域的新增前景，排除尾巴 ROI。不接纳全图预测中的玻璃反光弧。
4. 新增体素仍须满足底部新增前景与至少 5/6 侧面 mask 支持；没有放宽侧面投票阈值。1 mm 体素只接受通过 26 邻域连到原始最大身体分量的新增部分。
5. 渲染新增体素并裁剪到对应输入轮廓；只填旧深度为零的位置，保留原有全部非零深度值。新出现且未与任何旧前景相连的二维孤岛被保守拒绝。
6. 新像素单独保存为 `limb_added_pixels/`，可追溯、可撤销。深度为原生 1080×1200（宽×高）float32 PFM、毫米单位 camera-Z，背景为 0。

本次不是全模型重新渲染：它是保守的缺失像素补充。原有错误深度不会因此消失，拼接边界的深度也不是独立测得的真值。

## 检验结果

`verification.json` 独立重读 224 份深度图与对应 mask，结果通过：

| 检查 | 结果 |
|---|---:|
| 改动旧非零深度值 | 0 |
| 新增像素超出所用输入 mask | 0 |
| 底部尾巴 ROI 内改动 | 0 |
| 累计新增前景像素（全部 224 张） | 166,034 |
| 存在多个 ≥20 px 分量的图像数 | 69 → 44 |
| 最大分量外的像素总数 | 52,132 → 17,610 |
| PyMouseStudio 相关 unittest | 13 通过 |
| 原标注包 SHA256 | 不变 |

连通性数字不是准确率：其中包含尾巴、头部碎片等，而且真实遮挡可能让可见 mask 合理地分离。不能以“所有像素只有一个分量”为目标盲目连接。

## 交付文件

- `review/limb_repair_comparison_h264.mp4`：上排旧 mask（橙），中排新 mask（绿），下排 camera-Z 深度（100–320 mm 可视化范围）；7 列为 A–G，32 帧，8 fps 慢放，不是原始播放速度 52 fps。
- `review/limbs_000811_camC.png` 等：从左到右为 RGB、输入分割、修补前、修补后，保留原始像素比例的局部裁剪。
- `frame_*/rendered_depth_maps/`、`masks/`、`limb_added_pixels/`：新版本数据。
- `frames.jsonl`：源帧时间、视角与文件索引，路径相对于 AZL3 session。
- `report.json`：逐帧几何、DLC 审核与连通性统计。
- `config.json`、`verification.json`：约束、单位与交付校验。

脚本：`tools/repair_pymousestudio_limb_hull.py`、`tools/verify_pymousestudio_limb_delivery.py`。前者输出目录须尚不存在，避免意外覆盖；复现可使用 `--output` 指定新的试验目录。

## 后续方向

优先改善逐视角输入分割和时序稳定性，再考虑更细体素。DLC 适合充当可靠局部提示，不适合把低置信遮挡点直接连成实心肢体。可见 mask 与 amodal 身体完整性应分开：真正遮挡的区域应标记不确定/不可见，不能仅为连通而生成监督真值。

当前所有新增结果仍为未人工验证的伪标注，`train_allowed=false`。标注包、训练入口及原版本保持不变。
