- 本机先排查相机/深度共用尺度、数据覆盖与其他视角保留；诊断机制需要新配对验证，不能靠继续重复小池认定因果。

- PanoMouse 已下载、适配且真实底视/细爪标注已看图确认，优先作语义/划分审计后的 2D 数据候选；其鼠体重投影中位数/平均数不等于标定板误差。OSF 新相机候选虽修复数值反畸变失败，粗物体验证未显示改善，仍等待合作者原始标定、实测尺寸和逐点材料。
- 后续先报告中位数、平均数和缺失，再补覆盖、尾部及身份互换；不改写旧协议验收。本文不启动新训练、不自动准入数据，也不恢复自动唤醒。

## 已完成 v2 的冻结复核

## 已完成的训练修订

旧联合训练在 step13,568 保存后停止，冻结对照取消。当前纯几何臂从发布权重重新开始，不实例化 KeypointHead；没有定位损失经随机 head 回传 encoder。采用[纯几何协议](pure_geometry_bottom_20261018.md)：

- 已知真实装置使用给定 K/E；未知相机监督来自 6 套重新摆放并渲染的训练 rig 和 DANNCE1，另 2 套渲染 rig 整套留出。
- 每更新混合 8 样本，真实人工对应监督从第一更新占 25%；重复单 rig 原视频相机步为 0%，DANNCE1 相机步 6.25%，Water 仅作 3.125% 几何回放。有效标注与几何监督按实际可用内容准入。
- 旋转测地线损失；发布模型训练样本梯度校准定权；累积后 clip10；500 更新 warmup、余弦衰减、最终 EMA 主评价及 raw 对照。末次恢复段裁剪比例仍约 89.5%，梯度冲突和频繁裁剪尚不能宣称解决。
- 两次运行时优化均先保存并验证模型、优化器、EMA、RNG、固定 schedule 和采样位置，再从完整状态继续；测试更新全部丢弃。

[4 个 DataLoader workers](bottom_geometry_workers_resume_20261018.md)使普通训练更新吞吐约为原来的 **1.075 倍**，数据等待下降约 98.5%；不是整次作业提速 1.5–2 倍。[物理 batch 检查](bottom_geometry_physical_batch_20261018.md)中，整网 BF16 batch2/4 未过预登记数值门槛，正式接入的是 **encoder 仍逐样本、仅 camera/depth head FP32 批处理上限4**。有效 batch 始终8，顺序和逐样本损失归约不变。该路径梯度相对 L2 偏差约 0.0065%，普通更新吞吐约 1.247 倍，按诊断频率估计摊销约 1.238 倍；均不包含验证、存盘和启动，不能乘作整个实验墙钟加速。显存余量或瞬时 GPU 利用率不代替端到端计时，物理打包本身也不是泛化收益。

## 后续顺序与验收

1. **先诊断并修复几何。** 固定本轮最终证据及失败门槛；在训练样本上复核相机坐标/尺度、相机＋深度联动、各项共享梯度及裁剪，不以测试集调损失。扩大独立底视 rig、姿态与外观覆盖，保留侧/顶视回放；新增数据须先登记训练、开发与独立确认用途。已知装置部署优先使用提供的标定，demo 的标定接线仍需单独实现和验证。
2. **再执行预登记几何配对 G0/G1。** [配对协议 v2](bottom_domain_paired_v2_20261018.md)已登记，尚未执行完整配对，完整配对训练器尚待实现。两臂同发布起点、同 seed17、同 4,000 更新、同 8 样本顺序与目标；G0 冻结 encoder 仅训几何 heads，G1 另解冻最后两层。不能把本轮可行性臂追认为 G1，再事后减一个冻结臂。若诊断要求改变数据或目标，先登记新版本，再对两臂同时应用。当前启动器退出后不自动调度该比较。
3. **几何通过后才训练 2D head。** 固定通过验收的最终 EMA；先冻结 encoder/几何 heads、detach 特征，仅以 LR2e-4 训练随机五点 head 至训练损失收敛。真实标注贯穿；没有有效五点监督的 Water/视频不消耗定位更新。随后从同一个已收敛 head 分叉，比较继续冻结与解冻最后两层，保持数据/预算一致，沿用 warmup 与 EMA，并重新检查几何保留。冻结几何 head 参数不保证共享 encoder 改变后其输出不变。
4. **最后推进 3D 关键点。** 必须先通过底视相机、基础几何和 2D 定位验收；自动五点定位、毫米精度与未知真实装置能力各自需要相应独立验证，不能由本轮人工射线重投影替代。H100 扩展、伪标签和时序实验继续作为条件后续，不覆盖当前几何失败。

几何门槛保持不变：未见 rig 底视旋转中位数/P95 至少各下降 30%，绝对旋转 P95≤10°、方向 P95≤15°；预测相机＋深度 coverage32 至少提高 5pp，并检查逐来源与其他视角的相机、形状及转移保留。已知装置的几何收益不能代替上述未知装置验收。后续数据或协议修订需保留本轮结果，不能放宽门槛后回填通过。

本次 GitHub 更新仅发布路线、协议记录及紧凑汇总，不发布数据、标注载荷、权重或完整实验输出，也不启动后续训练。
