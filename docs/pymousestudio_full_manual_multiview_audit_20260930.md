# PyMouseStudio 全量回标与多视角三维一致性审计

2026-09-30，两个完整回标包已解压归档并完成全量几何审计。数据齐全，鼻尖、尾根、前爪具备较好的多视角一致性；但不能把全部三角化坐标直接当高精度3D真值。当前主要风险是部分相机的系统偏差、背腹表面点和尾中间点的跨视角同源性，以及少数左右爪对应冲突。

本次只整理和诊断，没有训练、修正相机、移动标注点或解除留出集隔离。尾尖沿用负责人确认的现有标注，不使用距图像边缘阈值排除。

## 3D检验方法

使用原标注包的K及world_to_camera_mm，确认相机旋转正交、右手性、齐次矩阵结构及零畸变。世界单位沿用标定毫米；没有用动物尺寸重新定标，也没有把世界轴伪称地面对齐坐标。

对每帧每个点，至少两个可用视角才进行三角化。先用归一化DLT，再最小化像素重投影平方误差。分别报告以下结果：

1. **全视角最小二乘误差**：所有可用观测共同拟合，误差没有先筛小再统计。
2. **留一视角误差 LOO**：每次不使用待检查视角，用其他视角重建后投影到该视角。原有至少三个视角的点才有此结果，比参与拟合后的误差更能暴露不一致。
3. **稳健共识拟合**：遍历视角对产生候选，使用既有试验的固定15像素阈值，再重拟合。分别统计共识内误差、全部观测误差和共识覆盖率，不能只报告被选中观测的漂亮数字。
4. **极线距离**：检查每对相机的同名2D点能否满足固定标定约束。

共识至少3视角、正深度、最大三角化视线夹角至少2度，仅记为“通过本次几何诊断”，不是3D监督许可。300组没有发现拟合点落在参与相机后方或最大视线夹角小于2度的情况。两视角结果单独保留为弱证据。

几何实现通过已知3D点回投影重建、极线零误差和注入单视角离群点的测试。三角化、相机单位和重投影数值另外逐文件验证。

## 相机及对应关系线索

10个已确认槽位的LOO中位数：A22.16、B13.75、C12.95、D12.75、E13.30、F26.25、G14.25 px。camA和camF都需要关注，不能把问题全归为底视。

仅在开发集，用鼻尖、尾根、四爪计算“其他视角重投影减人工坐标”的方向偏差：AZL3、AZR2、EL2、EL2L2、ER3L2的camF水平中位偏差分别约+29.61、+27.53、+30.49、+26.60、+30.47px，垂直中位偏差约−1到−2px；AZR2L2、CR2、FR2、FR3的camF则约−1到−4px。所有序列所附camF内外参数数值相同。

**推断而非定论**：这种按序列分组的稳定横向偏差，应优先排查相机是否有位置变化、共用标定是否适用于全部拍摄、图像坐标处理链路及同步，不应直接认为全部是人工点位错误。尚未把坐标统一平移，也未通过真实标定板或硬件同步证据确认原因。玻璃折射/反射也未被普通镜头畸变矫正消除。

视觉检查CR2第1169帧时，后爪重投影出现明显交叉。只对左右标签做只读相对对应假设检验，A与B/D/F/G采用相反后爪对应时，视角对平均截断极线代价由43.24降至10.42px。CR2第389帧也有类似模式；EL2第454帧前爪的单视角相对交换代价由41.37降至16.92px。

这些是优先复核线索，不是自动换标签的依据。相对左右对应具有全局翻转歧义，A也不保证绝对正确；没有任何点名被程序交换。完整候选记录于 `paw_relative_parity_hypotheses`，留出候选仅作此次质量审计，不据此调整训练或阈值。

背部06/07误差明显高于鼻/前爪，视觉上也有体表纵向位置或轮廓选点漂移的迹象。**假设**是某些视角选到了各自剪影/毛发边界而非同一表面位置；这还需要逐组对照确认，当前不能单靠误差分离定义误差、标定误差和同步误差。
